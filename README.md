## 🛡️ AegisOS

<div align="center">

### `x86-64 Hobby Operating System`

<img src="https://img.shields.io/badge/STATUS-IN%20DEVELOPMENT-orange?style=for-the-badge"/>
<img src="https://img.shields.io/badge/ARCHITECTURE-x86--64-1565C0?style=for-the-badge"/>
<img src="https://img.shields.io/badge/PLATFORM-QEMU-FF6600?style=for-the-badge"/>

</div>

AegisOS is a final-year hobby operating system exploring a **functionally separated kernel architecture**.

Instead of relying on a single central kernel flow, the project explores independent kernel domains communicating through **direct Inter-Kernel Communication (IKC)**.

```text
                         AEGISOS
                            │
            ┌───────────────┼───────────────┐
            │               │               │
            ▼               ▼               ▼
       ┌─────────┐     ┌─────────┐     ┌─────────┐
       │ Process │     │ Memory  │     │ Network │
       │ Kernel  │     │ Kernel  │     │ Kernel  │
       └────┬────┘     └────┬────┘     └────┬────┘
            │               │               │
            └───────────────┼───────────────┘
                            │
                            ▼
                      ┌───────────┐
                      │  Storage  │
                      │  Kernel   │
                      └───────────┘
```

### 🔧 Technologies

`C` `x86-64 Assembly` `QEMU` `GDB` `Linux`

### 🎯 Current Development

- Bootloader
- x86-64 initialization
- CPU initialization
- Serial communication
- GDT
- Interrupt infrastructure
- Memory management
- Kernel domains
- Inter-Kernel Communication

## 🌐 NetSonic

<div align="center">

### `See the Network. Hear the Network.`

<img src="https://img.shields.io/badge/STATUS-IN%20DEVELOPMENT-00C853?style=for-the-badge"/>
<img src="https://img.shields.io/badge/BACKEND-FastAPI-009688?style=for-the-badge"/>
<img src="https://img.shields.io/badge/FRONTEND-React-61DAFB?style=for-the-badge"/>

</div>

NetSonic is a **network monitoring and sonification platform** designed to discover devices on an authorized local network, visualize network topology and transform network activity into sound.

```text
                     LOCAL NETWORK
                           │
                           ▼
                  ┌────────────────┐
                  │    DISCOVERY   │
                  └───────┬────────┘
                          │
                          ▼
                  ┌────────────────┐
                  │     DEVICES    │
                  │   IP / MAC     │
                  └───────┬────────┘
                          │
                          ▼
                  ┌────────────────┐
                  │    TOPOLOGY    │
                  └───────┬────────┘
                          │
                          ▼
                  ┌────────────────┐
                  │    TRAFFIC     │
                  └───────┬────────┘
                          │
                          ▼
                  ┌────────────────┐
                  │ 🔊 SONIFICATION│
                  └────────────────┘
```

### 🔧 Technologies

`FastAPI` `Python` `React` `TypeScript` `SQLite` `Cytoscape`

### 🎯 Features

- 🔍 Local network discovery
- 📡 Device discovery
- 🌐 IP / MAC information
- 🗺️ Network topology visualization
- 📊 Network monitoring
- 🔊 Network activity sonification
- ⚡ REST APIs
- 🗄️ SQLite persistence
